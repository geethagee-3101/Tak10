# Task 10 – Simple KPI Tracking Sheet

## 📌 Project Overview
This project focuses on creating a simple KPI tracking sheet using Microsoft Excel. It converts raw retail order data into useful business metrics for monitoring sales performance.

## 🎯 Objectives
- Track total revenue.
- Calculate total units sold.
- Calculate average order value.
- Identify the top-selling product.
- Automate KPI calculations using Excel formulas.

## 🛠️ Tools Used
- Microsoft Excel
- Excel Tables
- SUM, SUMIFS, AVERAGEIFS
- INDEX and MATCH

## 📊 KPIs Tracked
1. **Total Revenue:** Total sales revenue after discounts.
2. **Units Sold:** Total quantity of products sold.
3. **Average Order Value:** Average revenue per order row.
4. **Top Product:** Product with the highest total units sold.

## 📁 Files Included
- `Task10_Simple_KPI_Tracking_Sheet.xlsx` – Excel workbook with KPI summary, formulas, and sample order data.
- `Task10_Simple_KPI_Tracking_Report.docx` – Project report explaining the objectives, methodology, and findings.

## ⚙️ Key Features
- Automated KPI calculations.
- Structured order data.
- Currency and number formatting.
- Formulas designed to include new rows added to the Excel Table.
- A compact, business-friendly KPI summary.

## 💡 Key Learnings
- Understanding important retail business KPIs.
- Using Excel formulas for sales analysis.
- Converting raw data into meaningful business insights.
- Maintaining accurate and automatically updated reports.

## 📝 Conclusion
This project demonstrates how Excel can be used to create a simple, automated KPI dashboard that helps a retail business monitor revenue, sales volume, average order value, and product demand.

**Note:** The workbook uses illustrative sample retail data for demonstration purposes.
